# **App Name**: CueScore

## Core Features:

- User Authentication: User authentication and roles (Admin, Player, Guest) using email/password.
- Player Profiles: Player profiles with name, picture, contact details, skill level, statistics, and dynamic handicap system.
- Match History: Record and display past match history for each player, including opponent, score, and date.
- Tournament Management: Create and manage tournaments with round-robin, knockout, or league formats; schedule matches.
- Leaderboard Display: Display of tournament leaderboards, match schedules, and player statistics.
- Handicap Advisor: AI-powered tool for handicap suggestions, based on a player's match history and skill level.
- Push Notifications: Push notifications for upcoming matches and tournament updates.

## Style Guidelines:

- Primary color: Dark moss green (#4A614A), evoking the traditional green felt of a snooker table.
- Background color: Deep charcoal (#292F33), creating a sophisticated and focused atmosphere.
- Accent color: Warm gold (#B8860B), used sparingly to highlight key elements such as scores and notification badges.
- Font: 'Inter', a grotesque-style sans-serif for clear legibility in the app's headlines and body text.
- Simple, clean icons representing players, tournaments, and statistics; icons to match warm gold accent color.
- A clean and structured layout that prioritizes match schedules and player statistics.
- Subtle transitions and animations on data updates.
